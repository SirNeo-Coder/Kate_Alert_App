# student-app

The Android phone app carried by students.

Written in **Java**. This folder is intended to be opened in **Android Studio**;
the Gradle project files will be generated there.

## Responsibilities

- Read the student's personal NFC tag to raise an emergency alert.
- Read GPS to identify the nearest campus building.
- Let the student confirm or correct the building, floor and room.
- Send the alert to the monitoring system.

## Data it depends on

- `../shared/campus_buildings.json` — the campus building list.
- `../shared/alert_record.json` — the alert record format.
