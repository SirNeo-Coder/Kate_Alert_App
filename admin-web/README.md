# admin-web

The monitoring web application used by campus administrators.

## Responsibilities

- Display a map of the campus.
- Display active alerts as they arrive.
- Indicate which building each student in distress is in, along with floor and room.

## Folders

- `src/` — application source.
- `public/` — static assets served to the browser (map images, icons).

## Data it depends on

- `../shared/campus_buildings.jsonc` — the campus building list, including map coordinates.
- `../shared/alert_record.jsonc` — the alert record format.
