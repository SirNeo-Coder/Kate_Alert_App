## Data still missing

**Building coordinates.** Latitude and longitude for each building in
[[pup-sta-mesa-campus]]. Originally to be collected by hand from Google Maps
(right-click a building, the coordinates appear at the top of the menu). The
setup screen in [[admin-web]] can capture them from a click instead.

**Floor counts and room numbers.** Not published anywhere online. This lives with
PUP's Physical Planning and Development Office.

## Set aside on purpose

**Sequencing.** Coordinates go in first, rooms stay empty. That alone makes the
system demonstrable — alert raised, three buildings offered, marker appears on
the admin map. Rooms only refine something already working.

**How rooms get entered** on the setup screen. Deferred to the web app
development phase.

**What the admin sees** with the student's name shown versus hidden. Deferred.

One thing to keep in mind when that comes back up: the tag is unique to the
student, so an alert record can always be traced back to them whatever the toggle
says. The honest description of the toggle is "show the name on the admin map, or
don't" — not "the school cannot know who it was."
